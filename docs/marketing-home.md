# Homepage marketing Nalka

Ce fichier sert de référence rapide pour la nouvelle homepage marketing (visiteurs non connectés).

## Sections prévues

- **Navbar marketing** : logo Nalka (violet), liens `Comment ça marche`, `Confidentialité`, `Exemples`, action secondaire `Se connecter`, CTA primaire `Créer un événement` en pill noir.
- **Hero** (itération 1) : accroche forte “Événements privés, organisés en un seul lien.”, sous-texte expliquant les modules activables (RSVP, cadeaux, Secret Santa, dépenses) dans un hub privé.
  - Bloc formulaire : champ e-mail + bouton “Créer votre événement” avec redirection vers la création (après connexion). Mention sous le champ : “Pas de mot de passe. Lien magique sécurisé.”
  - Lien texte : “Voir un événement démo”.
  - Visuel : carte d’événement flottante à droite avec “Vos événements” + badge “3 actifs”, carte d’aperçu (titre d’événement, date/heure, stats RSVPs / cadeaux réservés / montant dû, badge “Hôte”).
- **Étapes / fonctionnement** : à décliner dans une prochaine itération (scroll anchor `#fonctionnement`).
- **Exemples / preuves** : vitrine d’événements ou cas d’usage (anchor `#exemples`).
- **Footer** : conserve le footer global existant pour l’instant.

## Notes visuelles

- Typo sobre (Inter + serif display existant), taille h1 large, textes en français.
